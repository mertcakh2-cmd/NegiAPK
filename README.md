# Vimmy

A Vim-inspired terminal text editor for Termux.

## Install

chmod +x build.sh
./build.sh

## Run

vimmy
vimmy file.txt

## Controls

i       Insert mode
Esc     Normal mode
h j k l Movement
0       Start of line
$       End of line
x       Delete character
dd      Delete line
o       New line below

:w      Save
:w name Save as
:q      Quit
:q!     Force quit
:wq     Save and quit
:help   Help
